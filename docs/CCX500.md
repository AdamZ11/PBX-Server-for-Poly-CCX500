# Poly CCX500 – konfiguráció és hardveres ellenőrzőlista

Ez a dokumentum leírja, mely Poly paramétereket generálja a `ccxpbx`, és mit kell valódi CCX500-on ellenőrizni.
A paraméterek a Poly UC Software (PolyOS) adminisztrátori útmutatóján alapulnak, hardveren még nem teszteltem őket.
Ha valamelyik nem működik az aktuális firmware-rel, a webes felületen az **Egyedi Poly paraméterek**
(Beállítások: mindenkire, Telefon: csak arra a készülékre) mezőben javítható, és szólj, hogy a generátorba is bekerüljön.

## Fájlok, amiket a telefon letölt

| URL (`/prov/...`) | Tartalom |
|---|---|
| `<mac>.cfg` / `000000000000.cfg` | master: `CONFIG_FILES="ccx/<mac>-phone.cfg, ccx/site.cfg"`, firmware útvonal, feltöltési mappák |
| `ccx/site.cfg` | közös beállítások (szerver, idő, kodekek, digit map, soft key-ek, paging, REST API, jelszavak) |
| `ccx/<mac>-phone.cfg` | vonalak (`reg.N.*`), gombkiosztás (`lineKey.*`), BLF (`attendant.resourceList.*`), gyorshívók (`efk.*`), egyedi paraméterek |
| `000000000000-directory.xml` | telefonkönyv a mellékekből |
| PUT `logs/`, `overrides/`, `contacts/`, `calllists/` | a telefon feltöltései (napló, helyi módosítások, névjegyek, híváslista) |

A konfigurációt a szerver mindig az adatbázisból generálja, ezért nem tud elavult fájlt kiszolgálni.
Az előnézet a webes felületen a *Telefon → Generált konfig* menüpont alatt érhető el.

## Funkciók → paraméterek → ellenőrzés

| # | Funkció | Generált paraméterek | Ellenőrzés a telefonon |
|---|---|---|---|
| 1 | Alapprofil | `device.baseProfile=Generic` | Indulás után SIP módban van (nem Teams/Zoom) |
| 2 | Provisioning rögzítése | `device.prov.serverType/serverName/user/password` (+ `.set=1`) | Újraindítás után is a ccxpbx-ről tölt (*Status → Platform → Configuration*) |
| 3 | Admin jelszó | `device.auth.localAdminPassword` | A webfelületre (https://telefon-ip) a `PHONE_ADMIN_PASSWORD`-del lehet belépni |
| 4 | Regisztráció | `reg.N.address/auth.userId/auth.password/server.1.*` | Zöld vonal ikon, a dashboardon *Reachable* |
| 5 | Szinkronizálás | `voIpProt.SIP.specialEvent.checkSync.alwaysReboot=0` | *Konfig szinkronizálás* gomb → a telefon újratölt (csak akkor indul újra, ha kell) |
| 6 | Újraindítás SIP-en | NOTIFY `Event: check-sync;reboot=true` | *Újraindítás (SIP)* gomb → reboot. Ha nem indul újra, a REST újraindítást használd |
| 7 | REST API | `apps.restapi.enabled=1` | *Eszközinfó* gomb JSON-t ad vissza (modell, firmware, MAC) |
| 8 | BLF | `attendant.reg=1`, `attendant.resourceList.N.*`, `lineKey.P.category=BLF` | Gomb színe változik, amikor a figyelt mellék hív / csörög; csörgéskor megnyomva felveszi |
| 9 | Célzott felvétel | `feature.directedCallPickup.enabled=1`, `call.directedCallPickupString=**` | BLF gomb csörgés közben → felveszi |
| 10 | Park gomb | `attendant.resourceList.N.type=automata` a 700-ra | Hívás közben megnyomva → a hívás parkolódik, a 70x BLF piros lesz |
| 11 | Park soft key | `softkey.1.action=#72$Tdtmf$` | Hívás közben a *Park* gomb → bemondja a park helyet |
| 12 | Felvétel soft key | `softkey.2.action=*1$Tdtmf$` | Hívás közben megnyomva → fájl jön létre a `/var/spool/asterisk/monitor` alatt |
| 13 | Hangposta / MWI | `msg.mwi.N.callBackMode=contact`, `msg.mwi.N.callBack=*97`, `up.oneTouchVoiceMail=1` | Hangüzenet után villog az MWI lámpa; *Messages* → hangposta |
| 14 | Intercom | `voIpProt.SIP.alertInfo.1.value="Ring Answer"`, `class=autoAnswer`, `call.autoAnswer.micMute` | `*80<mellék>` → automatikusan felveszi kihangosítva |
| 15 | Multicast paging | `ptt.pageMode.enable=1`, `ptt.address`, `ptt.port`, csoport 1 | *Paging* gombbal a többi telefon megszólal (a switchen engedélyezni kell a multicastot) |
| 16 | Gyorshívó | `efk.efklist.N.action.string=<szám>$Tinvite$`, `lineKey.P.category=EFK` | Gomb → hívás |
| 17 | Digit map | `dialplan.digitmap` (a számozási tervből generálva) | Mellékszám után azonnal hív, külső szám után 3 mp-et vár |
| 18 | Idő / DST | `tcpIpApp.sntp.*`, EU nyári időszámítás szabály | Helyes idő, márciusi és októberi átállás |
| 19 | Kodekek | `voice.codecPref.G722=1, G711_A=2, G711_Mu=3` | Hívás közben *Call info*: G.722 |
| 20 | Telefonkönyv | `000000000000-directory.xml` | A *Contacts* listában ott vannak a mellékek; szerkesztés után a `contacts/<mac>-directory.xml` feltöltődik |
| 21 | Naplók | `LOG_FILE_DIRECTORY=logs` | *Telefon → feltöltött fájlok* listában megjelenik a `<mac>-app.log` |
| 22 | TLS + SRTP | `voIpProt.server.1.transport=TLS`, `sec.srtp.*`, `device.sec.TLS.customCaCert1` | Lakat ikon a hívásban. **Kísérleti funkció**, csak akkor kapcsold be, ha UDP-n már minden működik |
| 23 | Firmware | master `APP_FILE_PATH=firmware/<fájl>` | Új firmware feltöltése és kiválasztása után a telefon frissít |
| 24 | Éjszakai ellenőrzés | `prov.polling.*` | A telefon naponta 03:00-kor ellenőrzi a konfigot |

## Tipikus hibák

* **401 a provisioningnál**: a felhasználónév vagy jelszó nem egyezik. Teszteléshez a *Hitelesítés* átállítható *Nincs*-re.
* **A telefon nem regisztrál**: a dashboardon nézd meg, hogy van-e kontakt, és `asterisk -rvvv` alatt `pjsip show endpoints`.
  Ellenőrizd, hogy a szerver IP-je (*Beállítások → Szerver IP*) jó-e.
* **BLF nem változik**: `asterisk -rx "core show hints"` – meg kell lennie a hintnek, és a telefonnak fel kell iratkoznia
  (`pjsip show subscriptions inbound`).
* **Egyirányú hang trönkön**: állítsd be a *Publikus IP*-t és a *Helyi hálózat*-ot, majd indítsd újra az Asteriskot.
* **A telefonon tett módosítások felülírják a szervert**: *Telefon oldali override-ok törlése*.

## Hasznos Asterisk parancsok

```
asterisk -rvvv
pjsip show contacts
pjsip show endpoint 2001
core show hints
pjsip send notify poly-check-sync endpoint 2001
pjsip set logger on          # SIP üzenetek a konzolon
```
